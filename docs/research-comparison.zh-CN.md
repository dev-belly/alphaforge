## 研究问题与固定规则

复杂模型能否改善一个简单、可执行规则明确的研究组合？

比较等权、固定 12–1 动量、Ridge、LightGBM 和 Ridge 去掉 `log_market_cap` 特征。模型分别使用事先确定的 **11、29、42** 三个种子；每个方法都报告原成本和双倍成本。没有根据测试结果挑种子、调参数或选择上线模型。

四份原始镜像文件的 SHA-256 与旧实验相同。监督数据集为 **840,736 行 × 24 个特征**，哈希为 `8906ace6a84d22bdc78a05fedcd75498d964dd56555da00492892f5eb7a9a7cd`，也与旧实验一致。六折共同产生 **551,698 条**预测，预测期为 2014-01-02 至 2019-10-16；组合结果期为 2015-01-02 至 2019-10-31，每个实验保留 1,217 个交易日收益。

所有分数策略对可选股票按分数取前 50 名并等权；分数相同时按股票代码排序。等权基准持有全部可预测的合格股票，分散程度因此不同。月度调仓，信号后一个交易日执行。基础成本假设为佣金 2bp、滑点 5bp、冲击系数 10bp，参与率上限 10%。

## 结果：复杂度与收益质量分开判断

| 基础假设成本下 | 净年化收益 | 净 Sharpe | 最大回撤 |
| --- | ---: | ---: | ---: |
| 等权基准 | 12.75% | 1.141 | -18.70% |
| 固定 12–1 动量 | 11.38% | 0.871 | -23.40% |
| Ridge | 12.77% | 1.009 | -21.65% |
| LightGBM，三个种子均值 | 17.07% | 1.252 | -22.10% |
| Ridge 去掉显式规模特征 | 12.43% | 0.970 | -21.57% |

Ridge 的年化收益与等权接近，但 Sharpe 更低、回撤更大。LightGBM 在这个样本里有较高的收益和 Sharpe，回撤仍比等权更深；不能只挑一列指标讲故事。

双倍成本下，LightGBM 的平均净年化收益为 **16.36%**、Sharpe 为 **1.206**；基础成本下三种子 Sharpe 的总体标准差约 **0.034**。种子差异只反映本次拟合的随机性，不是跨市场样本的置信区间。

去掉规模列后的实验只移除模型中的 `log_market_cap` 预测变量，没有撤销更早的规模中性化。它不是“完全不使用规模信息”的实验。新旧结果间的变化也不能全部归因于某一个修复：评价代码和依赖版本都已有变化。

## 复现与核验

需要 Python 3.12。从仓库根目录执行以下命令；Windows 也可以直接使用 `.\.venv\Scripts\python.exe` 替换 `python`，无需激活虚拟环境。

```bash
python -m pip install -e ".[viz]" -c research/requirements-session-refit.txt
python scripts/verify_comparison.py docs/experiments/real-sp500-session-v2
```

上面两条命令核验已保存的研究结果，不联网下载市场数据、不重新拟合模型。完整重训：

```bash
python scripts/fetch_real_data.py --start 2010-01-01 --end 2019-11-14
python scripts/run_comparison.py --out research/comparison
python scripts/verify_comparison.py research/comparison
```

下载地址中的镜像可能更新。先把新的 `data/processed/DATA_ASSURANCE.json` 的 `raw_sha256` 与保存的 `summary.json` 中 `source_assurance.raw_sha256` 比较；不相同就是不同来源输入，不能声称重现了本次实验。Parquet 文件的字节会受写入库版本影响；本次四份原始文件及最终监督表身份都相同。

`summary.json` 记录模型参数、种子、成本、实际窗口配置、关键依赖版本及研究模块的文件哈希。原环境约束保存在[依赖文件](https://github.com/dev-belly/alphaforge/blob/main/research/requirements-session-refit.txt)。旧归档文件不修改；新目录禁用 Git 换行转换，Windows 与 Linux 都按原字节核验。

## 仍然存在的数据范围

- 当前成员及加入日期没有覆盖完整的历史退出、退市名单，仍有生存者选择偏差。
- 财务数据使用假设发布滞后，缺少实际首次披露与历史修订记录；本次有效模型输入是 24 个价格、成交量及其衍生特征。
- 规模使用美元成交量代理，实际市值不可得；基准是 SPY 价格回报代理，不含该来源未提供的分红。
- 这些是历史情景下、扣除模型成本的研究结果，不能当作实际成交或未来收益的证明。

`--require-complete-sources` 会拒绝当前镜像的数据范围。修正训练切分没有补齐这些来源缺口。
